How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Name it “Sebaaly news portal” and pick an expiry (e.g. 1 year).
  3. Resource owner: the Sebaaly Audit Firm GitHub account. Repository access: Only select repositories → the website repository.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate, copy the token and paste it here. Don't share it — it can edit the website.
